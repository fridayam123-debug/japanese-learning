# 일본어 학습 프로그램 설계 문서

작성일: 2026-05-10
대상: 초등학생 (글자는 알고 단어 학습 중인 단계)

## 1. 개요

태블릿에서 오프라인으로 동작하는 단일 HTML 파일 형태의 일본어 학습 프로그램. 초등학생 아들이 주제별로 단어와 예문을 익히고, 퀴즈로 점검하고, 상황별 회화를 따라할 수 있다.

## 2. 목표 및 제약

- **단일 HTML 파일** — 태블릿에 저장 후 더블클릭 실행, 인터넷 불필요
- **외부 의존성 0** — 라이브러리·서버·빌드 단계 없음, 브라우저 내장 기능만 사용
- **태블릿 터치 우선** — 버튼·카드·타이포 모두 큼직하게
- **초등 친화 디자인** — 깔끔하지만 유치하지 않게

## 3. 콘텐츠 범위

### 주제 (8개)
학교 / 음식 / 동물 / 가족 / 일상 / 숫자·시간 / 여행 / 요리

### 주제별 데이터
- 단어: 주제당 20~30개
- 예문: 단어당 1개
- 회화: 상황당 5~6턴 대화

### 단어 데이터 구조
```json
{
  "topic": "동물",
  "words": [
    {
      "kana": "ねこ",
      "kanji": "猫",
      "meaning": "고양이",
      "example": {
        "jp": "ねこが すきです。",
        "ko": "고양이를 좋아합니다."
      }
    }
  ],
  "dialogues": [
    {
      "scene": "동물원에서",
      "lines": [
        {"jp": "ぞうが おおきいですね。", "ko": "코끼리가 크네요."},
        {"jp": "そうですね。", "ko": "그렇네요."}
      ]
    }
  ]
}
```

## 4. 화면 구성

### 메인 화면
- 상단: 앱 제목 + 우측에 **주제 선택 드롭다운** (8개 주제)
- 가운데: 큼직한 모드 카드 3개 — `플래시카드`, `퀴즈`, `회화`
- 하단: 학습 통계 — "오늘 ○개 학습 / 퀴즈 최고점 ○점"

### 플래시카드 모드
- 카드 앞면: 일본어(히라가나 큰 글씨 + 한자 작게 병기), 🔊 발음 버튼
- 카드 탭 → 뒷면으로 플립: 한국어 뜻 + 예문(jp/ko/🔊)
- 좌우 스와이프 또는 ← → 버튼으로 이전/다음
- 진도 표시: `5 / 25`

### 퀴즈 모드
- 4지선다 형식
  - 문제: "ねこ는 무슨 뜻?" 또는 "고양이를 일본어로?"
  - 보기: 같은 주제 단어 4개 (정답 1 + 오답 3 무작위)
- 정답 → ✓ 표시 + 점수 +10 + 짧은 효과음
- 오답 → ✗ 표시 + 정답 강조
- 10문제 1세트 → 최종 점수 결과 화면 (`다시 풀기` / `메인으로`)

### 회화 모드
- 상황 카드 목록 (예: 식당에서 / 학교에서 / 인사하기 / 길 묻기)
- 카드 선택 → 대화문 한 줄씩 표시
  - 일본어 (히라가나 + 한자), 🔊 버튼
  - `한국어 보기` 토글로 번역 표시/숨김
- 다음 줄 버튼으로 진행, 끝나면 `다시 듣기` / `상황 선택으로`

## 5. 핵심 기능

### TTS (발음 재생)
- `window.speechSynthesis` API + `SpeechSynthesisUtterance({lang: 'ja-JP'})`
- 모든 일본어 텍스트 옆 🔊 버튼 → 누르면 재생
- 브라우저에 일본어 음성이 없을 경우 대비: 첫 실행 시 음성 가용성 확인 후 안내

### 진도 저장 (localStorage)
- `localStorage` 키:
  - `jp.flashcards.viewed` — 본 카드 수
  - `jp.quiz.highScore` — 퀴즈 최고점
  - `jp.lastStudied` — 마지막 학습 날짜
- 메인 화면 통계 표시에 사용

### 주제 필터링
- 드롭다운에서 주제 선택 → 해당 주제 데이터만 모드에 공급
- 선택 상태도 `localStorage`에 저장

## 6. 디자인 톤

- **배경**: 화이트 (`#fff`) 또는 매우 옅은 베이지
- **포인트 컬러**: 파스텔 블루 (`#7BAFD4` 정도)
- **일본어 타이포**: 큰 글씨 (히라가나 48~64px), `serif` 계열로 가독성 ↑
- **한국어**: 부드러운 sans-serif (시스템 기본)
- **카드**: 둥근 모서리(`border-radius: 16px`), 부드러운 그림자
- **버튼**: 큼직하게(터치 영역 최소 64px), 누르는 피드백 명확하게
- **이모지 최소화** — 발음 🔊, 정답 ✓, 오답 ✗ 정도만

## 8. 구현 단위 (모듈 구분)

단일 HTML 파일이지만 `<script>` 안에서 모듈처럼 분리:

1. **데이터 모듈** — 8개 주제의 단어·예문·대화 JSON
2. **TTS 모듈** — `speak(text, lang='ja-JP')` 함수
3. **저장 모듈** — `loadProgress()`, `saveProgress()`
4. **라우터 모듈** — 메인 ↔ 모드 전환, 주제 변경 반영
5. **모드 모듈** — `Flashcard`, `Quiz`, `Conversation` 각각 독립 렌더링·상태
6. **UI 모듈** — 공통 버튼·카드 스타일, 헤더, 푸터

## 9. 성공 기준

- 태블릿 브라우저에서 더블클릭으로 실행, 인터넷 없이 모든 기능 동작
- 8개 주제 × 모드 3종이 모두 동작 (콘텐츠 빈자리 없음)
- 일본어 발음이 자연스럽게 재생됨
- 학습 진도가 다음 실행 시 유지됨
- 초등학생 혼자 메뉴 보고 사용할 수 있을 만큼 직관적

## 10. 향후 확장 (이번 범위 밖)

- 손글씨 입력으로 히라가나 쓰기 연습
- 음성 인식으로 발음 채점
- 부모 대시보드 (학습 시간·정답률)
- 데이터 추가 시 코드 수정 없이 별도 JSON 파일 로드
